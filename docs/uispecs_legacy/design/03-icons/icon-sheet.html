Icon set — 56 icons

Outlined icons on a 24×24 grid, 1.5px stroke, round caps and joins, live area inset to 3–21. Each icon is a single path so it can be stored as data, bound into a template, or emitted as a sprite symbol without restructuring. Colour comes from currentColor only — icons never carry their own colour.
